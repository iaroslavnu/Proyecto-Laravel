💈 Plataforma de Gestión de Citas para Barbería

Aplicación web full-stack para la reserva de citas online y la gestión de servicios de una barbería. Los clientes reservan su cita desde el navegador y los barberos gestionan horarios, servicios y estados de cada cita desde un panel de administración.


✨ Funcionalidades

La aplicación tiene tres roles, cada uno con su propio nivel de acceso:

👤 Cliente

Reserva de citas online.

✂️ Barbero

Panel para controlar sus citas.
Cancelación de citas.
Gestión de horarios, servicios y estados de cada cita.

👑 Barbero (dueño)

Todo lo que puede hacer un barbero.
Alta y baja de barberos.
Consulta de las citas de cada barbero.

General

Control de acceso por roles.
Validación de datos en formularios.
Interfaz responsive adaptada a móvil y escritorio.
